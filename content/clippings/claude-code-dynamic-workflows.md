## Claude Code 推出动态工作流

今天我们在 Claude Code 中推出**动态工作流**（dynamic workflows），帮助 Claude 端到端地完成最具挑战性的任务。以往需要按季度规划的工作，现在几天内即可完成。Claude 会动态编写编排脚本，在一个会话中运行数十到数百个并行的子代理，并在结果交付到你手中之前自行检查其工作。

有些问题太大，单个代理单次处理无法解决，尤其是在复杂的遗留代码库中：跨整个服务的 bug 排查、涉及数百个文件的迁移、一个你希望在提交前从各个角度压力测试的计划。动态工作流可以端到端地处理以上所有这些任务。

动态工作流今日起在 Claude Code CLI、桌面版和 VS Code 扩展中以**研究预览**形式提供，适用于 Max、Team 和 Enterprise（需管理员启用）方案，同时也可通过 Claude API、Amazon Bedrock、Vertex AI 和 Microsoft Foundry 使用。

> **注意**：动态工作流消耗的 token 可能远远超过典型的 Claude Code 会话，我们建议从一个范围明确的任务开始，以了解你工作场景中的实际用量。

为了获得最佳体验，请在使用动态工作流时开启**自动模式**（auto mode）。之后，你可以通过两种方式启动工作流：

1. 直接让 Claude 创建动态工作流（例如，"创建一个工作流"）
2. 打开一个名为 `ultracode` 的 Claude Code 专属设置。可通过 effort 菜单访问，它将 effort 级别设为 xhigh，同时让 Claude 自行决定何时使用工作流来处理你的任务

## 动态工作流实战

早期体验用户及 Anthropic 内部团队已将动态工作流用于广泛场景，包括：

- **跨代码库的 bug 排查、基于 profiler 的性能优化审计和安全审计**：Claude 并行搜索服务或代码库，然后对每个发现进行独立验证，确保报告揭示的是真实问题。同样的模式也适用于加固检查：跨整个代码库检查权限验证、输入校验和不安全模式。
- **大规模迁移和现代化改造**：Claude 可端到端处理框架替换、API 废弃迁移、跨越数千个文件的语言移植。
- **需要双重确认的关键工作**：当错误答案的代价很高时，工作流会让 Claude 独立进行多次尝试，并有对抗性代理在结果呈现给你之前尝试推翻它。

> 「动态工作流在跨大代码库的发现和审查任务中尤其有价值。我们在识别死代码和发现传统静态分析遗漏的清理机会方面看到了显著成效，帮助我们的工程师在维护和重构工作上更快推进。」
>
> — Alessio Vallero，Klarna 高级工程经理

>
> — Ken Takao，CyberAgent 首席系统工程师

### 用动态工作流重写 Bun

动态工作流规模能力的典型案例是 Bun 的近期重写。Jarred Sumner 使用动态工作流将 Bun 从 Zig 移植到 Rust，**99.8%** 的现有测试套件通过，约 75 万行 Rust 代码，从首次提交到合并仅用 **11 天**。其中一个工作流为 Zig 代码库中每个结构体字段映射了正确的 Rust 生命周期。下一个工作流则将每个 `.rs` 文件作为其对应 `.zig` 文件的行为等价移植版本写入，数百个代理并行工作，每个文件配备两个审查者。随后一个修复循环驱动构建和测试套件运行，直到两者均通过。移植完成后，一个夜间工作流处理了不必要的数据拷贝，并为每个修复提交 PR 等待最终审查。虽然尚未用于生产环境，但所有这一切都由动态工作流处理。Jarred 将在后续撰文分享更多细节。

## 工作原理

当工作流启动时，Claude 根据你的提示进行动态规划，将其分解为子任务，并将工作分发到并行运行的子代理中。结果在合并前经过检查，你得到的是一个统一的、经过协调的答案。代理们从独立角度处理问题，其他代理尝试反驳其发现，运行持续迭代直到答案收敛——这就是工作流能够达成单次处理无法企及的结果的方式。

动态工作流专为可延续数小时甚至数天的并行和长时间运行的工作而构建，处理以往需要数周才能完成的最复杂工程任务。进度在运行过程中保存，因此被中断的作业会从中断处继续，而非从头开始。由于协调发生在对话之外，无论任务规模多大，计划都能保持正轨。

需要指出的是，动态工作流消耗的用量显著高于典型的 Claude Code 会话。工作流首次触发时，Claude Code 会显示即将运行的内容并要求你确认。组织管理员也可以通过托管设置选择性禁用工作流。

## 入门指南

如果你使用的是 Max 或 Team 方案，或通过 API 使用 Claude Code，动态工作流默认开启。直接让 Claude 创建工作流，或打开 Claude Code 专属设置 `ultracode` 即可开始。如果你使用的是 Enterprise 方案，动态工作流在发布时默认关闭，管理员可在 Claude Code [设置](https://code.claude.com/docs/en/settings)中轻松更改。

阅读[文档](https://code.claude.com/docs/en/workflows)了解更多。
